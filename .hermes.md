# Hermes project context

Before continuing work in this repository, read `CILIWUNG_HANDOFF.md` completely and inspect current `git status`, relevant source files, and live ports. This repository is the SIMBA control plane for the Ciliwung multi-simulator project. The companion 3D and CupCarbon folders are outside this Git repository.

Preserve the architecture documented in the handoff:

- `Website/SIMBA/server.ts` is the authoritative backend.
- Ciliwung simulation state is in memory and streamed by SSE.
- CupCarbon is controlled over UDP ports 5101–5109.
- The 3D renderer consumes backend state in `mode=backend`.
- Hardware/ESP32 telemetry must stay isolated from simulation state.

Use Indonesian for collaboration, verify live outcomes, and never push or modify `main` unless the user explicitly requests it. When a new session starts, report the verified branch, current commit, tests, and any open limitation before making changes.
